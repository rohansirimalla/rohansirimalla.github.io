# Rohan Sirimalla Portfolio

React/Vite portfolio website for an Azure DevOps Engineer profile.

## Local run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to GitHub Pages

This repo includes `.github/workflows/pages.yml`.

After pushing to the `main` branch:

1. Go to **Repository → Settings → Pages**.
2. Under **Build and deployment**, select **GitHub Actions**.
3. Open the **Actions** tab and wait for the workflow to complete.
4. Your site should be available at `https://<your-github-username>.github.io`.

## Customize

Update `src/main.jsx` with your email, LinkedIn, GitHub, project repo URLs, resume link, and final project statuses.
